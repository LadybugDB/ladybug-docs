This page describes how to use [gdotv](https://gdotv.com/), a third-party desktop application that
integrates with Ladybug to provide a rich set of visualization and analysis features for your graph data.

:::note[When is it beneficial to use gdotv?]
gdotv provides a wealth of tools to support developers and data analysts working with graph databases.
At its core, it is an integrated development environment with which you can write and execute Ladybug
Cypher queries, and analyze the results interactively. It’s also built for large scale, high performance
graph visualization to analyze trends in your graph data. 
:::

## Key features

gdotv's Ladybug Cypher query editor offers a powerful suite of features to accelerate and enhance your
query writing experience, by offering essential development features:

- MCP Server
- Cypher syntax validation
- Autocomplete suggestions based on your graph data schema
- Embedded schema documentation so you can immediately identify the relevant labels and property keys for your nodes & edges
- Procedure autocomplete
- Query parameter support

## Connecting to Ladybug

gdotv directly connects to a local Ladybug database. First, open the gdotv application and click on the
"New Database Connection" button. You can select Ladybug from the list of supported databases as shown below.

<img src="/img/visualization/gdotv/gdotv-1.png" />

The next step is to point gdotv to the Ladybug database you want to connect to. To do this, either click
on the empty path selector, or drag-drop your Ladybug database file into the UI. By default, gdotv will try to
connect to the Ladybug database in read-write mode. If you want it to connect in read-only mode,
you can select the "Read Only" button shown. Once selected, you can click on "Test Connection"
to make sure that the connection is successful.

<img src="/img/visualization/gdotv/gdotv-2.png" />


## Query using Cypher

You're now ready to write and execute Cypher queries in gdotv! The default query is loaded in
the query editor, which can be executed by clicking on the "Play" button or pressing `Ctrl+Enter`
(or `Cmd+Enter` on macOS). You should see your graph data visualized in the main panel.

<img src="/img/visualization/gdotv/gdotv-3.png" />

The default visualization is a graph of the results, if you choose to `RETURN *` or return nodes,
relationships, or paths from your query. You can also choose to visualize the results as a table
by returning the properties of the nodes or relationships.

## MCP Server

gdotv includes its own MCP server, so AI agents such as Claude Code, Cursor, Codex and VS Code can
work with your Ladybug database directly through gdotv. The MCP server can write a Cypher query
based on your Ladybug schema, validate it, then run it and provide a link which opens the
result in gdotv. Further capabilities include being able to save queries as reports and put
together dashboards, both of which can be reused with parameters by your team.

gdotv's MCP server is secure by design. Anything gdotv can't verify as a read operation is refused
unless write operations are opted-in. This setting is connection specific and can be toggled via
the connection settings.

More information, including how to set it up, can be found in the [gdotv documentation](https://gdotv.com/docs/mcp-server/).

## No-code Ladybug Exploration

gdotv’s Data Explorer gives you the ability to quickly query your Ladybug instance without the
need to write a Cypher query, through the use of easily configured filters. Combined with their
graph exploration features, you can explore your Ladybug data in just a few clicks, with no prior
knowledge of Cypher!

## View graph schema

You can view the graph schema by clicking on the "Graph Schema" button in the left sidebar.
This displays the data model in a convenient layout that shows the node labels, relationship labels
and their associated properties (and their data types).

## Advanced features

In addition to basic Cypher query editing, gdotv offers a richer set of features to help
you explore, debug and analyze your graph data. Below are some of the key features:

#### Query history

Access your previous queries and quickly re-run them.

#### Save queries

Save your queries for future use, and organize them into folders.
Queries can be configured with Cypher parameters (e.g. `MATCH (s) RETURN s LIMIT $limit`) which
gdotv automatically detects and prompts you back for, meaning you can effectively create and
categorize parameterized reports against your Ladybug instance.

#### Advanced Graph Visualization Customization

gdotv offers a comprehensive set of features to
customize the look and feel of your graph visualizations, giving you the ability to create insightful
renderings of your graph data for analysis and demonstration purposes.

#### View query profile and explain query

You can also view Ladybug's internal query execution profile and get a detailed explanation of the query plan and
execution strategy.

#### Custom graph layouts

Choose from a variety of graph layouts to visualize your data
  - Force-directed layout (default)
  - Circular
  - Grid
  - Community layout
  - Tree layout (vertical and horizontal)

There are many more features to explore than what we've listed here! Please see gdotv's
[Ladybug integration page](https://gdotv.com/databases/ladybugdb/) that details
all the important features along with examples.
