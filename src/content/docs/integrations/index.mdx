Ladybug can run inside the platforms you already use, so you can query your existing
data as a graph with Cypher without moving it elsewhere.

## Available integrations

| Integration | Description |
|-------------|-------------|
| [Snowflake](/integrations/snowflake) | Run Ladybug as a Snowflake Native App and query Snowflake tables with Cypher. |
| [PostgreSQL](/integrations/postgres) | Run Cypher queries inside PostgreSQL with the `pg_ladybug` extension. |

:::note[Note]
These integrations are different from [attaching](/extensions/attach/rdbms) external
databases to a standalone Ladybug instance. Here, Ladybug runs *inside* the host
platform: queries execute against your Snowflake or PostgreSQL tables in place.
:::
